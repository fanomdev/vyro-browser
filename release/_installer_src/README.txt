VYRO Browser — Browse Beyond Limits.

Run vyro-browser.exe to start the browser.

Portable build: the file named "portable" tells VYRO to keep settings,
bookmarks, history and the password vault in the "vyro-data" folder next to
this executable. You can copy this folder to any drive or another computer.

Requires the WebView2 Evergreen runtime on Windows.
